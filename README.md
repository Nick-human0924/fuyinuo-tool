# 复依诺® 用量速算

面向医疗卫生专业人员的移动端优先单页 Web 计算工具。输入患者身高和体重后，可在本地实时计算体表面积（BSA）、理论剂量、理论支数、整支用量参考与理论抽取体积。

## 功能

- Mosteller 公式计算 BSA
- 70 mg/m² 标准方案
- 50 mg/m² 特殊起始/调整场景
- 10 mL:43 mg 固定规格与 4.3 mg/mL 浓度计算
- 整支剂量差异信息展示
- 异常输入柔和提示
- iPhone 与 Android 移动端适配
- 所有计算在浏览器本地完成，不采集、上传或保存患者数据

## 重要声明

仅供医疗卫生专业人士参考。

本工具用于辅助计算，不替代完整药品说明书、临床判断或医师处方。支数参考不替代按体表面积计算的实际给药剂量。实际处方、配制及剂量调整应由医疗专业人员依据经批准说明书及患者具体情况决定。
